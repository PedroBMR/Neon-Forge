# Anime Blacksmith

Jogo idle/clicker de forja de armas com estética anime/medieval, onde o jogador produz armas e evolui de rank F‑ a SSS+.

## O que já foi feito
- Protótipo de forja com progressão de níveis e salvamento automático.
- Sistema de upgrade de Tap/DPS e bots.
- Implementação do sistema de Ranks com faixas de preço (F‑ a SSS+).
- Cinco tipos de armas básicas: Espada, Machado, Adaga, Lança e Clava.

## Como funciona
- Cada arma recebe status (dano, velocidade, durabilidade, materiais, peso, qualidade).
- Clientes comuns e VIP compram armas; VIPs pagam até 3× mais.
- Moeda interna para melhorias e itens cosméticos.
- Salvamento automático do progresso.

## Monetização
- Skins cosméticas para a forja.
- Efeitos visuais premium.
- Pacotes de armas temáticas.
- Moeda premium: “Essência de Mana Ancestral”.

## Próximos passos
- Novos tipos de armas (katanas, foices, espadas duplas).
- Mais estatísticas de RPG (crítico, resistência mágica, etc.).
- Leaderboard offline/online com top 10 armas.
- Eventos sazonais e armas temáticas.
- Suporte multiplataforma.
